# EventSync User Manual

## 1. User Roles
- Student: browse events, RSVP, and chat inside joined event rooms.
- Organizer: everything a student can do, plus create and edit their own events.

## 2. Register and Log In
1. Open the frontend in the browser.
2. Choose `Create account`.
3. Enter your full name, email, password, and role.
4. After registration, you are redirected into the protected app.
5. Existing users can use `Login` instead.

## 3. Browse Events
1. Open the `Events` page from the navbar.
2. Review the event cards or month calendar snapshot.
3. Click `Open live detail` to see the full event page.

## 4. Join an Event
1. Open an event detail page.
2. Click `Join Event`.
3. Confirm the attendee counter updates.
4. If another tab is open on the same event, the counter should update there too.

## 5. Use Event Chat
1. Open the same event detail page after joining.
2. Type a message in the chat composer.
3. Click `Send`.
4. Other attendees in the room should see the message instantly.

## 6. Create an Event as an Organizer
1. Log in with an organizer account.
2. Use the `Create Event` button in the navbar, dashboard, or events page.
3. Fill in title, description, location, category, date/time, status, and tags.
4. Upload an optional poster image.
5. Submit the form to publish the event.

## 7. Edit an Event as an Organizer
1. Open your event card or event detail page.
2. Click `Edit event`.
3. Update the information or replace/remove the poster.
4. Save changes and verify the detail page reflects them.

## 8. Logout
1. Click `Logout` in the navbar.
2. Protected routes will redirect back to the login page.
